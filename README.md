### 🔹 Smart Network-Based Automated Software Deployment
**Final Year Major Project — Master–Slave Architecture**
**Stack:** Python · Socket Programming (TCP/UDP) · Multi-threading · Tkinter · SQLite · TLS · SHA-256 · psutil

A resilient Master–Slave system for zero-touch software provisioning and configuration management across an entire computer lab from a single control point.

- Designed a Tkinter-based GUI for the centralized Master node with real-time inventory and client status logging via SQLite
- Engineered multi-threaded Python agents (Windows Services) that cut manual installation time from 5+ hours (180 clients) to a single 2-minute automated run
- Implemented a persistent, asynchronous command queue and heartbeat mechanism for reliable task completion and real-time connectivity telemetry
- Secured the deployment pipeline with TLS encryption and SHA-256 integrity checks on all distributed binaries
- Published as a research paper in IJIRIS (see Publications below)

### 🔹 Rakta-Seva Connect — Emergency Blood Donation App
**Stack:** Kotlin · Android Studio · Firebase Authentication · Cloud Firestore · Firebase Cloud Messaging (FCM) · Figma

An Android app that shortens the gap between an urgent blood request and a matching donor, built end-to-end during my internship at MindMatrix.

- Architected the app around Firebase Cloud Firestore for real-time sync, with OTP-based authentication guarding every donor and requester profile
- Built the emergency-request flow so nearby eligible donors get an instant FCM push the moment a request goes live, cutting the time it takes to find a match
- Encoded a 90-day cooldown rule directly into the donation logic to keep donors medically eligible without manual tracking
- Kept donors' contact details hidden by default, revealing them only once a request is explicitly accepted, to balance urgency with privacy
- Backed the build with formal SRS documentation, DFDs, and use-case models so the system design could scale beyond the MVP

🔗 **Repository:** [github.com/rohitkvanjre/Rakta-Seva Connect](https://github.com/rohitkvanjre/Rakta_Seva_Connect.git)
